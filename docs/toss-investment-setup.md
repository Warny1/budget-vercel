# 토스증권 조회 연결

2026-10-26 공식 OpenAPI 명세로 구현. 국내·미국 보유 주식 조회만 지원한다. 현금 예수금, 해외 옵션, 채권은 포함되지 않는다. KRW/USD를 별도 표시하고 수수료·세금 차감 전 금액을 사용한다. 평가손익은 가계부 수입·지출·저축 데이터에 쓰지 않으며 조회 결과도 브라우저 메모리에만 보관한다.

## 연결 전 준비

1. 토스증권 WTS → 설정 → Open API에서 client_id와 client_secret 발급.
2. 서버의 **고정 출발 IP**를 토스증권 허용 IP에 등록. Vercel 웹사이트의 도메인 IP나 개인 맥북의 IP는 Vercel 서버 출발 IP가 아니다. Vercel에서 고정 egress를 제공하는 배포 구성을 확인하거나 고정 IP 서버를 선택해야 한다. 유료 옵션을 임의로 구매하지 않는다.
3. 같은 API client를 여러 서비스에서 사용하지 않는다. 토큰 재발급 시 이전 토큰이 무효화되므로 전용 client 사용. 다중 서버 인스턴스에서는 토큰을 공유 저장소/락으로 관리하거나 단일 서버로 운영해야 한다. 현재 구현의 토큰·조회 캐시는 프로세스 단위다. 다중 인스턴스 상시 운영은 이 조치 전 활성화하지 않는다.
4. 계좌 식별자 accountSeq는 토스증권 `GET /api/v1/accounts`로 확인한다. 실계좌번호가 아니다. 공식 명세상 일반 종합매매 계좌 대상이며 자녀 계좌는 제외.

## 서버 환경변수 (공개 config.js에 넣지 않음)

- `TOSS_CLIENT_ID`
- `TOSS_CLIENT_SECRET`
- `TOSS_ACCOUNT_SEQ`
- `TOSS_VIEWER_TOKEN_HASH`: 앱 공유 로그인 → 자산 → 투자 → 연결 설정 → 가계부 연결 확인값 보기에서 나온 SHA-256 확인값.

토스 키·토큰은 채팅, 저장소, JSON 가계부 백업에 넣지 않는다. 서버 비밀 환경변수 설정 화면에서 입력한다. 현재 공유 로그인 자격증명을 가진 가족만 조회할 수 있다. 공유 아이디/비밀번호 변경 시 연결 확인값도 갱신한다. 서버 환경변수를 삭제하거나 토스증권에서 client를 폐기하면 연결을 해제할 수 있다.

## 활성화 검증

환경변수와 고정 IP를 준비한 뒤 배포하고 `자산 → 투자 → 불러오기`에서 토스증권 앱의 보유 수량·통화별 평가금액과 대조한다. 미설정 시 연결 준비 안내, 오류 시 이전 조회 결과를 명시한다. 토스 실계좌로는 아직 검증하지 않았으므로 실제 연결 완료로 보고하지 않는다.

## 구현·검증

`api/toss-holdings.js`: 조회 권한 확인, no-store, 30초 캐시와 동시 요청 합치기. 임의 URL이나 계좌 입력을 받지 않음.
`lib/toss-client.cjs`: 토큰 발급과 지정 계좌 GET holdings만 호출. 인증 실패 시 토큰 폐기, 12초 요청 타임아웃. 자동 매매/이체 경로 없음.
`node scripts/test-toss.cjs`: 공식 응답 예제로 정상/빈계좌/혼합통화/인증실패/호출제한 검사.
